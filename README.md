## About

Senior Platform Developer at [DTDC](https://www.dtdc.in), based in Gurugram. I work the platform layer in PHP and Python: service APIs, data, realtime, auth, and the consoles operators use.

- Laravel for the core platform, and FastAPI where the service is async
- MySQL, PostgreSQL, and MongoDB as the record. Redis for hot state. Elasticsearch for search. Kafka for streams
- JWT, OAuth, and OTP across session and token auth
- Next.js, React, Vue, Tailwind, and Angular for operator consoles
- Docker, Nginx, and AWS around the runtime
- Queues, workers, and WebSockets so slow work stays off the request
